# Working in the Xmip estate

The rules for working here live in [CONTRIBUTING.md](CONTRIBUTING.md) — what
to read before writing, how work lands, the hard-learned rules and the
working area. Read that file before changing anything.

This file is a pointer on purpose. The rules are the same for a person and
for a model, so they are not kept under a name that belongs to one tool
(the owner, 2026-09-20). It exists only because some tools load a file of
this name; `CLAUDE.md` is the same pointer for the tools that load that one.
Do not move a rule back into it: one subject has one document (ADR-0020,
clause 8).
